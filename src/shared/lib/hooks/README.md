# shared/lib/hooks

Generic React hooks with no business logic, as generated by shadcn (`hooks` alias in `components.json`).

- `useIsMobile` – `true` below the mobile breakpoint
- `useHighlightedCode` – syntax-highlights code with `../highlighter`

Import through `@/shared/lib/hooks`. Hooks tied to a business domain belong in that slice's `model` segment instead.
